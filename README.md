# BootLauncher

BootLauncher is a lightweight Android application that automatically launches your selected apps after the device finishes booting.

It is designed for kiosk devices, dedicated tablets, digital signage, and anyone who wants their favorite apps to start automatically after every reboot.

## Features

*  Launch app automatically after device startup (Ver1.0)
*  Simple and easy-to-use interface
*  Lightweight with minimal resource usage

## Installation

1. Download the latest APK from the **Releases** page.
2. Install the application on your Android device.
3. Open BootLauncher and grant any required permissions.
4. Select the app you want to launch after boot.
5. Restart your device to verify everything works as expected.

## Requirements

* Android 8.0 (Oreo) or newer like Android 15 (Vanilla Ice Cream)
* Permission to receive the device boot event
